## How to use a prompt

1. Open a prompt file and copy the block under **Prompt**.
2. Paste it into Grok Imagine. Timed beats (0–4s, 4–8s…) are meant for a single multi-shot clip; image-to-video entries also need a reference image.
3. Generate, then re-roll or tweak the parts that matter to you.

Some creators shared only part of their prompt, or only described the result in their post; those files say so.
